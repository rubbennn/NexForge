# ⚔️ NexForge

NexForge is a desktop Valorant player tracker built with Python and CustomTkinter.

Search for a Valorant player using their Riot ID and region to view account information, competitive rank data, ranked progress, and recent match performance through a clean desktop interface.

## ✨ Features

- 🔎 Search players by Riot ID (`Name#Tag`)
- 🌍 Support for multiple Valorant regions
- 👤 Player account information
  - Username
  - Region
  - Account level
  - Player card
- 🏆 Competitive information
  - Current rank
  - Rank Rating (RR)
  - Current ELO
  - RR gained/lost in the last match
  - Highest rank achieved
  - Peak season
- 📈 Ranked progress visualization
- 📊 Recent competitive performance
  - Win Rate
  - K/D Ratio
  - Headshot Percentage
- 🎮 Recent competitive match data
- 🖥️ Custom desktop interface built with CustomTkinter

## 🛠️ Built With

- Python
- CustomTkinter
- Tkinter
- Pillow
- Requests
- HenrikDev Valorant API
- Valorant API
